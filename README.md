 🎬 Netflix Content Analysis
     Project Overview
This project explores the Netflix dataset to uncover trends in content distribution, production, ratings, and genres. The analysis was performed using Python for data cleaning and exploratory data analysis (EDA), with Power BI used to build an interactive dashboard.
Objectives
- Clean and prepare the Netflix dataset for analysis.
- Explore the distribution of Movies and TV Shows.
- Analyze content additions over the years.
- Identify the top content-producing countries.
- Determine the most common genres and content ratings.
- Generate insights and recommendations based on the findings.
  ##Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
- Power BI
- Git & GitHub

## 📂 Project Workflow
1. Imported the Netflix dataset into Jupyter Notebook.
2. Cleaned missing values and duplicate records.
3. Converted date columns into the appropriate format.
4. Performed Exploratory Data Analysis (EDA).
5. Created visualizations to identify trends and patterns.
6. Designed an interactive Power BI dashboard.
7. Generated business insights and recommendations.

## 📊 Key Analyses
- Movies vs TV Shows Distribution

## 💡 Key Insights
- Movies make up the majority of Netflix's content library.
- The United States contributes the largest share of Netflix titles.
- Drama, International Movies, and Comedy are among the most common genres.
- TV-MA and TV-14 are the most frequent content ratings.
- Netflix experienced significant growth in content additions over several years before growth became more moderate.

## ✅ Recommendations
- Expand investment in international content to reach broader audiences.
- Increase the production of TV Shows to encourage long-term viewer engagement.
- Grow family-friendly content to appeal to more age groups.
- Improve metadata quality to enhance content discovery and recommendations.
